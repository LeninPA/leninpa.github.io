# Código Rápido y Replicable
## ¿Qué vas a aprender en este curso?

En un contexto donde la inteligencia artificial transforma el desarrollo de software, **entender y optimizar los aspectos subyacentes del código** se vuelve esencial. Esta capacidad no solo **mejora el rendimiento**, sino que también brinda una ventaja competitiva. En este taller aprenderemos cómo lograr una mayor reproducibilidad en nuestros proyectos usando:

1. Bash
2. Python
3. GitHub
4. Contenedores

## Sesiones, actividades y temario

Vamos a tener 10 sesiones de 2 horas para dar un total de 20 horas de clase. Se darán presencialmente en [REDACTED] y se transmitirán en vivo por YouTube. En caso de ser necesario podemos tener sesiones de asesoría adicional. Los temas a ver son:

1. **Sesión 1.** Introducción al Supercómputo
    1. ¿Qué es el supercómputo? 
    2. ¿Qué es Linux?
    3. El sistema de archivos de Linux
    4. Comandos básicos de Linux
    5. Editores de texto en la terminal
    6. Metacaracteres
    7. Conexión a máquinas remotas mediante `ssh`
2. **Sesión 2.** Introducción a las Utilerías de Linux
    1. Filtros en Linux
    2. Utilerías básicas
    3. `AWK` y otras utilerías
    3. Concatenación de Comandos
    4. Introducción a la ciencia de datos desde la terminal
3. **Sesión 3.** Escritura de scripts en Linux
    1. Permisos de archivos
    2. Variables
    3. Argumentos en un script
    4. Estructuras de flujo y de control
    5. Cron y automatización desde terminal
4. **Sesión 4.** Git y GitHub
    1. Git
        1. Sistemas de control de versiones
        2. Commit y otros comandos básicos
        3. Ramas
        4. Reverts
    2. GitHub
        1. Creación de una cuenta en GitHub
        2. Clonación de repositorios remotos
        3. Milestones, issues y herramientas para el manejo de proyectos
        4. Colaboración remota con GitHub
        5. READMEs y el lenguaje Markdown
5. **Sesión 5.** Manejo de paqueterías de Python con Conda
   1. ¿Para qué entornos para Python?
   2. Instalación de Anaconda y Miniconda
   3. Creación de entornos con Conda
   4. Importación y exportación de entornos con conda
   5. Estructura de proyectos con Python
6. **Sesión 6.** Introducción a los contenedores con Apptainer
   1. Contenedores y máquinas virtuales
   2. Importación de contenedores y OCI
   3. Diferencias entre Docker y Apptainer
   4. Escritura de archivos de definición
   5. Creación de contenedores
   6. Ejecución de scripts en contenedores
7. **Sesión 7.** Python para aplicaciones de terminal
   1. Buenas prácticas de codificación
      1. Comentarios en Python
      2. Docstrings en Python
      3. Automatic compliance
   2. Usando varios archivos con Python
   3. Argparse para la creación de interfaces de línea de comandos
8. **Sesión 8.** Temas selectos de Python de Alto Rendimiento I. Numba y cómputo en paralelo
9.  **Sesión 9.** Temas selectos de Python de Alto Rendimiento II. PyOMP y memoria compartida
10. **Sesión 10.** Temas selectos de Python de Alto Rendimiento II. MPI for Python y memoria no compartida

## Conocimientos previos

Se requieren conocimientos básicos de programación. Particularmente escritura de objetos y de funciones. Es recomendable tener experiencia con línea de comandos, pero no es necesario.

## Evaluación

Se requiere entregar un proyecto final que utilice todas las herramientas vistas en el curso. Es decir:

- El código debe de estar almacenado en un repositorio de GitHub
- Debe de ejecutarse mediante un contenedor de Apptainer
- Debe ser programado en Python con sus dependencias claramente identificadas en un entorno tipo Conda.

Una rúbrica detallada se les hará llegar antes de la entrega del proyecto. Se evaluará como aprobado/no aprobado. 

## Metodología de enseñanza

Se impartirá mediante instrucción directa los temas a revisar. Por la naturaleza intensiva del curso, se dejará tarea para complementar y reafirmar los conocimientos vistos en clase que servirán para construir el proyecto.

## Bibliografía
### Bash
Aprender Bash es aprender un sistema de magia con reglas estrictas. Tiene una curva de aprendizaje imponente, pero que una vez que entiendes la magnitud de su poder se vuelve inseparable de tu día a día. En cuanto a sitios web puedes revisar:

- [Bash Academy](https://guide.bash.academy/). Blogs detallados con respecto a la funcionalidad de Bash con diagramas.
- [OverTheWire Wargames: Bandit](https://overthewire.org/wargames/bandit/). Te permite aprender Linux usando la computadora de alguien más y varios comandos conforme se van necesitando.
- [Devhints cheatsheet](https://devhints.io/bash). Explica los conceptos más básicos que puedes llegar a necesitar para empezar a escribir y comprender scripts de Bash.

En cuanto a libros puedes leer manuales que se compartirán en Classroom.
